## 状态

**待定。** 项目自身开源许可证**尚未确定**，本 ADR 不授予、也不默认任何许可。当前状态必须被如实传达，不得被后续文档或发行材料默认为「已开源」。

## 背景

- 目标仓库 `MokoKing666/yingmu` 经已认证接口确认 404（账号下 8 个公开仓库中无同名或 `yingmu-player`，无覆盖风险）；GitHub 连接器已认证为 `MokoKing666`，但其 GitHub App 无「创建仓库」权限（403）；本机 `git push` 通道不可达（`github.com:443` 直连超时、代理返回 502），仅 `api.github.com` 直连可达；用户提供的本地凭据文件为标准格式的 classic PAT，但实测 `GET /user` 返回 401（凭据已失效）——其**内容未被读取输出，也未写入任何代码、提交、remote URL 或日志**。完整源码已打包为 git bundle 并保留全部提交历史，待有效凭据就绪后可一键推送。许可证状态与「未授权第三方复制或分发」的声明不受推送状态影响。
- 项目引入了大量第三方依赖（React、Vite、Tailwind、Motion、Zustand、PixiJS、Tauri、Rust crates、libmpv、FFmpeg、libplacebo、MiSans 字体、NSIS、WebView2 等），各自有不同许可证与分发限制。
- 涉及 GPL / LGPL、编解码专利池、第三方商标（Dolby、DTS、HDR10+ 等）、字体授权与 Dolby 技术授权等法务问题。
- 需求：明确「代码公开」与「授权使用」的区别，避免第三方误以为可自由复制、修改或分发。

## 决策

1. **项目开源许可证尚未确定**：不默认 MIT / Apache-2.0 / GPL 或任何许可；在正式确定并写入 `LICENSE` 前，项目处于「无明确开源授权」状态。
2. **仓库仅为代码审查公开**：当前仓库内容（若后续可访问）**仅用于代码审查**，**未授权第三方复制、修改、再分发或用于构建衍生产品**。
3. **商标与技术授权**：Dolby、Dolby Vision、Dolby Atmos、DTS、HDR10+ 等商标与相关技术需**单独授权**；本项目**未获得 Dolby 官方认证、未使用 Dolby 官方 Logo、未获任何相关授权**。文中相关名称仅为技术格式的中性指称。
4. **字体**：本机已安装 MiSans，但系统字体文件**不打包进仓库**（`.gitignore` 排除字体二进制）；正式发行如需再分发，必须从官方渠道获取并遵守其授权，具体条款**待法务确认**。
5. **第三方依赖**：逐项许可证、使用方式、分发限制与 GPL / LGPL / 专利 / 商标 / Dolby 技术授权专项审查见根目录 `THIRD_PARTY_NOTICES.md`；**不确定项一律标注「待法务确认」，不编造许可证名称**。
6. **不得臆断**：「不能假定动态链接自动免除许可证义务」；发行前必须完成许可证选型与法务确认。

## 后果

正面：

- 明确记录「未授权」状态，避免第三方误用，也避免项目自身在无许可证情况下被默认开源。
- 把许可证、商标、专利、字体、Dolby 授权问题集中在 `THIRD_PARTY_NOTICES.md`，便于发行前统一法务审查。

负面 / 待解决：

- 在许可证确定前，项目**不得**对外宣称「开源」，也**不得**被第三方假定可自由复制或分发。
- 发行（尤其包含 GPL/LGPL 组件、编解码器、字体、Dolby 相关能力描述）前，必须完成：项目许可证选型、第三方许可证与分发义务核对、专利与商标授权确认、字体再分发授权确认。
- 本项目**未获得任何 Dolby / DTS 官方认证**，不得宣称支持原生 DV / Atmos 输出或任何认证（见 `docs/dolby-compatibility/*`）。
- GPL / LGPL、专利、商标、Dolby 技术授权的具体结论**待法务确认**，本文不编造许可证名称或授权范围。
